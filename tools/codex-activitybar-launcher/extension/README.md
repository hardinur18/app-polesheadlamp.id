# Codex Activity Bar Launcher

This local extension adds a `Codex` icon to the left Activity Bar in Windsurf or VS Code.

Use it when you want a stable left-side shortcut even if the official `openai.chatgpt` extension prefers the secondary sidebar on the right.

What it does:

- Adds a `Codex` icon to the left Activity Bar
- Shows quick actions to open the installed Codex sidebar
- Provides a shortcut to create a new Codex agent

This extension expects the official `openai.chatgpt` extension to already be installed.
